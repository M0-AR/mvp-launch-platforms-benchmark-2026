🗓️ The 4-week playbook (copy-paste)

  1. Today ($0, 10 min): join free queues (Uneed, MicroLaunch, TinyLaunch, Launching Next). Write ONE question: "100 signups in 28 days from strangers?" + one metric.
  2. Week 1 — waitlist: BetaList + idea-first post + landing page + build log. Goal: first 50 emails.
  3. Week 2 — weekly board: Peerlist Mon–Sun. Read every comment, fix headline + screenshot. Dev tools add DevHunt.
  4. Week 3 — daily boards, different days: Uneed Wed + Fazier Thu. Ship fixes in 48h, say so publicly.
  5. Week 4 — one big day: Product Hunt (Tue–Thu) OR Show HN, never both. Friday: story-post (not pitch) where buyers live.
  6. Ongoing: SaaSHub + AlternativeTo permanents; one plain-text buyer answer/week; lifetime-deal sites only for cash+volume.

Cost: $0 slow path · ~$115 fast path (Uneed $29.99 + Fazier $49 + LaunchIgniter $15 + SaaSCity $19.99 = dates + 4 permanent links). Never pay for votes.

❓ FAQ

Should I still launch on Product Hunt?

Yes — if you bring ~50 voters on a Tue–Thu you choose. It converts an audience you have; it rarely creates one from zero.

Only 3 platforms — which?

BetaList (before) + Peerlist (weekly, forgiving) + Uneed (daily + newsletter + permanent page). Add Product Hunt week 4 with proof.

$0 vs ~$115?

$0 = join all free queues today (1–5 months). $115 = guaranteed dates + 4 permanent links + weeks of visibility. Neither buys votes.

Dev tool?

Peerlist + Show HN + DevHunt same week. Working demo + short README beat slogans.

Non-tech buyers?

Founder-board applause converts ~0. Validate with 5 buyer interviews + landing page + 50–200 private beta in the buyers' community.
